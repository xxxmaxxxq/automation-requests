# Automation: заявки по автомобилю

Автоматизация рабочего процесса оценщика: от фотографий автомобиля до
заполненной карточки заявки во внутреннем портале страховой компании.
Скрипт сам распознаёт госномер, VIN, марку и модель, выбирает главное фото,
раскладывает файлы по папкам и заполняет форму в браузере.

> Python 3 · Playwright (CDP) · Windows OCR · PowerShell · BAT-лаунчеры

## Что умеет

| Блок | Что делает |
|---|---|
| Фотографии | забирает снимки с iPhone, раскладывает по папкам месяца и заявки |
| OCR | распознаёт текст со снимков штатными средствами Windows |
| Распознавание | госномер, VIN, марка и модель по СТС и фото |
| Главное фото | выбирает подходящий кадр автомобиля для карточки |
| Заполнение | поднимает браузер по CDP и заполняет форму заявки на портале |
| Обновление | отдельный сценарий правит уже созданную заявку |
| Тренажёр | локальная копия формы (`training_site.py`) для отладки без портала |

## Файлы

| Файл | Назначение |
|---|---|
| `create_request.py` | основной сценарий: фото → распознавание → создание заявки |
| `update_current_request.py` | обновление текущей заявки |
| `transfer_iphone_photos.ps1` | перенос фотографий с iPhone |
| `windows_ocr.ps1` | OCR средствами Windows |
| `training_site.py` / `training_site.html` | локальный тренировочный портал |
| `start_work_browser_9222.bat` | запуск Chrome с открытым портом отладки 9222 |
| `run_full_project.bat` | полный прогон |
| `01_OPEN_ME/` | BAT-лаунчеры под типовые сценарии |

## Запуск

```powershell
pip install playwright
python -m playwright install chromium

set PORTAL_URL=https://portal.example.com/requests
set PORTAL_LOGIN=...
set PORTAL_PASSWORD=...

start_work_browser_9222.bat
python create_request.py
```

Скрипт подключается к уже открытому браузеру по CDP (`http://127.0.0.1:9222`),
поэтому сессия и вход остаются под контролем оператора.

## Настройки через переменные окружения

| Переменная | Что задаёт |
|---|---|
| `PORTAL_URL` | адрес внутреннего портала |
| `PORTAL_LOGIN` / `PORTAL_PASSWORD` | учётные данные портала |
| `CUSTOMER_TEXT` | заказчик по умолчанию |
| `SEND_FILE_EMAIL` | адрес для отправки документов |
| `DESKTOP_ROOT_NAME` | корневая папка с фотографиями на рабочем столе |
| `VISIT_REGION_*`, `VISIT_CITY_*`, `VISIT_STREET_*`, `VISIT_HOUSE_*` | адрес осмотра |

## Приватность

Репозиторий публичный, поэтому в коде нет логинов, паролей, адреса внутреннего
портала, реальных VIN, госномеров и контактов — всё вынесено в переменные
окружения либо заменено демо-значениями. Результаты OCR и сканы страниц
в репозиторий не выкладываются.
